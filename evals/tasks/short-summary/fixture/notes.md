# 维护小工具的想法（随手记）

- 起因：最近电脑内存经常占满，硬盘也快满了，Docker 一个就占了七十多 G。
- 想做一个小而美、占用低的 Mac 维护工具，常驻菜单栏。
- 只给我自己的 Mac 用。之前想过做 Windows 版给同学用，后来决定不做了，跨平台没意义。
- 清理：闲置文件、缓存、不用的应用都能扫出来，但要逐项勾选，不能一键全删。
- Docker：能看到占了多少，能清构建缓存，但不动容器、镜像和数据卷。
- Homebrew：能看到装了哪些应用，能更新、能卸载；需要管理员密码的复杂卸载脚本先列出原因、暂不执行。
- 监控 Codex 的内存，后台工具可以一个个停用和重新启用，但不能影响正在跑的任务。
- 首页要有一个健康分数。
- 菜单栏面板：点开能即时刷新、即时操作，点别处自动收起。
- 内存目标：窗口关掉、面板收起后全部进程不超过 60 MB，打开时不超过 120 MB。
- 优化内存的时候不能删功能，也不能缩小统计范围来凑数字。
- 外观：深灰、灰白加淡紫配色，不要绿色。Logo 用字符风格的小猫，保留眨眼和摆尾动画。
- 以后可能考虑用 Rust 重写核心，但现在先把体验做好。
- 做完要在本机实测，再更新本机安装的版本，源码传 GitHub 并写好 README。
