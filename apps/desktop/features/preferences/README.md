# Personal instructions and Skills

Desktop-only native folder review, immutable SKILL.md import, explicit version activation and
revocation, and bounded personal instruction editing. The module owns its commands, snapshot,
validation, native picker and dialog. It uses trusted configuration callbacks; renderer text
never supplies arbitrary file operations. Only SKILL.md is imported; scripts and references are
not loaded. Pending, empty, failed, review, enabled and revoked states remain visible.
