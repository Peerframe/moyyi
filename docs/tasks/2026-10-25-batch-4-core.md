## Delivery scope

The existing batch 4 acceptance list in the [canonical handoff](2026-10-24-codex-handoff.md)
remains unchanged. Implementation covers the self-owned loop/executor, real store wiring,
approval protocol, cancellation/steering, error/retry classification, budgets, startup recovery,
minimal context, base policy and a pinned argument validator behind a pure-core port.

`npm run demo:scripted` now exercises a complete model → tool → stored result → model flow.
`npm run eval:core` independently checks eight deterministic lifecycle/policy scenarios through
the public runtime protocol. [core.md](../core.md) explains usage and limits, and
[ADR 0008](../decisions/0008-core-execution.md) records decisions and primary-source evidence.
All OpenBot failure scenarios have scoped evidence in [provenance](../openbot-provenance.md);
no OpenBot implementation was copied.

The frozen persisted v1, SQLite schema, public 30-task checkers and layer rules are unchanged.
Store session enumeration is an additive port for recovery of active runs with no effects.
`ajv@8.20.0` is a validation library, not an agent runtime. No new production tool capability
or paid provider is introduced. The default policy remains read-only.
