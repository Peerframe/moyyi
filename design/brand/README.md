# Moyyi visual identity work

Preferred baseline: the original rounded `m` + tail [brandkit identity](2026-10-28-brandkit/README.md). The owner said the later [four shark directions](2026-10-28-logo-directions/README.md) were worse than the earlier version. A minimal tail-only refinement is available for comparison; it is not approved and does not replace the original.

Owner decisions on 2026-10-28:

- Name: `moyyi`, Chinese name `墨一`; character: a shark girl.
- Personality: cool-headed and intelligent, with a small playful streak.
- The first tall, mature character direction was rejected. The owner supplied a blue-haired chibi reference; subsequent character work follows it.
- The owner requested their downloaded logo-design skill. The source was found at `/Users/yxflc/.claude/skills/brandkit/SKILL.md`, and the current logo and overview follow that skill.
- The owner then requested several distinct blue-and-white logo directions with more obvious shark characteristics. The four-way comparison follows the same brandkit skill and keeps the chibi character unchanged.
- After comparing those directions, the owner preferred the earlier version. Preserve the simple `m` + tail structure; the interpretation is that further iteration should retain its rounded, restrained identity rather than add a full shark, face, gills or a speech bubble.

Only `2026-10-28-brandkit/` and this README are tracked in git (owner decision Z-2, 2026-10-29). The other folders and zip archives below stay on the owner's machine and are ignored by git, so their links resolve only locally. Product UI rules derived from this identity are in [docs/design.md](../../docs/design.md).

`2026-10-28-v1/` is rejected visual history. `2026-10-28-chibi-v2/` contains the reference-led character and an intermediate avatar logo. The character is reused in the current brandkit proposal; the intermediate avatar logo is not the current logo direction.

All deliverables are visual concepts. No production application assets or product code were changed. Existing concurrent changes outside `design/` belong to other work and were preserved.
