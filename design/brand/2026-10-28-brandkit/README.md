# Moyyi / 墨一 — brandkit identity proposal

This is the owner's preferred baseline after comparing four later logo directions, created with the downloaded [brandkit skill](/Users/yxflc/.claude/skills/brandkit/SKILL.md) and built-in ImageGen. It is not yet an approved production identity. The original `logo.png` remains unchanged.

## Direction

Moyyi is a personal general-purpose agent. Its visual character is a clever, calm, slightly playful chibi shark girl. The owner's reference sets the blue hair, light blue cardigan, large round head, compact body, and small shark tail. The earlier tall black-haired fashion direction was rejected and is retained only as history.

The logo applies brandkit's monogram-plus-meaning method: a softly rounded lowercase `m` with a restrained shark-tail terminal. The goal is a simple mark that works alongside the more detailed character. The palette uses ink navy, periwinkle, pale mist, and offwhite. Small-scale and monochrome applications on the overview are concept illustrations, not production certification.
